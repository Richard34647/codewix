01 Getting Started

Welcome to CodeWix — the AI-powered web development platform that lets you design, build, and ship websites entirely in your browser. No setup, no installs, no toolchain headaches.

Creating an Account

Click Sign Up on the homepage. You can register with an email address or sign in with Google. You'll need to verify your email before accessing the workspace.

Navigating the Dashboard

Once signed in, your dashboard gives you access to every part of the platform:

  • Workspace — a full-featured IDE with live preview.
  • AI Assistant — chat with advanced models to generate, debug, and explain code.
  • Page Builder — visual, drag-and-drop site builder with no code required.
  • Learn — interactive coding lessons from beginner to advanced.
  • Explore — a gallery of sites built by the CodeWix community.
💡
Tip: Every project autosaves to your account — you can close the tab and pick up right where you left off.

02 The Workspace (IDE)

The CodeWix Workspace is a professional-grade, browser-based IDE with first-class support for HTML, CSS, JavaScript, PHP, and Python.

Files & Code Editor

The left pane is your File Explorer — create, rename, or upload assets (images, fonts, data files). The center pane is a syntax-highlighted editor with autocomplete and bracket matching powered by CodeMirror.

Live Preview

The right pane renders your site in real time. Hit Build & Run or just keep typing — the preview updates automatically whenever your files change.

📎
File uploads: Free users can upload files up to 300 KB. Pro users can upload up to 5 MB per file.

03 AI Assistant

The CodeWix AI Assistant is your always-on coding partner. It can write new files, fix bugs, explain unfamiliar code, and even generate images.

Using the Chat

Try a prompt like "Build a responsive landing page for a coffee shop with a contact form". The AI returns ready-to-use code inside a code block. Click 🔥 Apply to IDE to import it straight into your workspace as a new file — no copy-pasting required.

Voice Notes

Prefer to speak? Click the 🎤 microphone button. The AI listens and transcribes your voice into the prompt box in real time.

Image Generation

Ask for an image — e.g., "Generate an image of a futuristic car" — and the assistant will return it rendered inline using the integrated image backend.

⚠️
Rate limits: Free users get a daily token allowance. Hit Upgrade for unlimited usage and access to premium models.

04 Page Builder

A visual, WYSIWYG editor for users who want beautiful sites without touching code. It works like WordPress or Wix — but ships directly into the CodeWix Workspace.

How to Use It

  • Add blocks: Click "Header", "Text", "Image", or "Section" in the left sidebar to drop them onto the page.
  • Edit text: Click directly on any text block and start typing.
  • Customize colors: Use the toolbar color pickers to change backgrounds, headings, and body text.
  • Multi-page: Under "Pages", type a name and click + to create additional pages (e.g., About, Contact).
  • Save: Click Save to CodeWix to push the generated project into your Workspace.

05 Publishing Sites

When a project is ready, publish it in seconds — no build step, no FTP, no server config.

How to Publish

Open the Publish tab, pick a project from the dropdown, choose a unique slug (e.g., my-cool-site), and click Publish.

Your site is instantly live at codewix.com/s/my-cool-site — share the link anywhere.
