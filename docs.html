Getting Started

Welcome to CodeWix, the ultimate AI-powered web development platform. CodeWix allows you to build websites, write code, and generate AI content all in one place.

Creating an Account

To get started, click on the Sign Up button on the homepage. You can register using your email address or sign in securely with Google. You will be required to verify your email address before you can access the workspace.

Navigating the Dashboard

Once logged in, you will land on your Dashboard. From here, you have access to:

  • Workspace: A full-featured code editor (IDE) with live preview.
  • AI Assistant: A chat interface to talk to AI models like Llama 3 and GPT.
  • Page Builder: A visual drag-and-drop website builder.
  • Learn: Interactive coding lessons.
  • Explore: A gallery of websites built by other CodeWix users.

The Workspace (IDE)

The CodeWix Workspace is a powerful browser-based IDE. It comes with built-in support for HTML, CSS, and JavaScript.

Files & Code Editor

On the left, you have the File Explorer. You can create new files, rename them, or upload assets (images, fonts) from your computer. The center panel is the code editor, which features syntax highlighting and autocomplete.

Live Preview

The right panel shows a real-time preview of your website. Whenever you type code and hit Build & Run, the preview updates instantly.

AI Assistant

The CodeWix AI Assistant is your personal coding companion. It can write code, debug errors, generate images, and explain complex concepts.

Using the Chat

Simply type a prompt like "Build a responsive landing page for a coffee shop with a contact form". The AI will generate the code and wrap it in a code block. Click 🔥 Apply to IDE to instantly load the generated code into your workspace!

Voice Notes (VN)

Don't feel like typing? Click the 🎤 Microphone icon at the bottom of the chat. The AI will listen to you speak and transcribe your voice into text automatically.

Image Generation

Ask the AI to generate an image (e.g., "Generate an image of a futuristic car"). It will automatically use our integrated backend image generator to display it.

Page Builder

The Page Builder is a visual tool designed for users who want to create beautiful websites without writing any code. It works similarly to WordPress or Wix.

How to use it

  • Add Blocks: Click on blocks like "Header", "Text", or "Image" in the left sidebar to add them to the page.
  • Edit Text: Click directly on any text on the page and start typing to edit it.
  • Colors: Use the color pickers in the top toolbar to change the background, heading colors, and text colors of the entire site.
  • Multi-page: Enter a name in the "Pages" section and click `+` to create new pages (e.g., About Us, Contact).
  • Save: Click Save to CodeWix to push the project to your Workspace.

Publishing Sites

Once you have built a project (either via the IDE or Page Builder), it's time to share it with the world.

How to Publish

Go to the Publish tab. Select the project from the dropdown, give it a unique URL slug (e.g., my-cool-site), and click Publish.

Your site will instantly go live at codewix.com/s/my-cool-site. You can share this link with anyone!

Custom Domains PRO

Free users get a CodeWix subdomain. Pro users can connect custom domains (like www.mycompany.com) and remove the "Built with CodeWix" watermark.
